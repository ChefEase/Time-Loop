# Audio direction

**Direction only. Do not compose a full soundtrack or produce final audio yet.**

Repeated sounds become a learnable clock. Church bells, bus brakes, café bell, dog bark, school bell, train horn, collision, welder ignition, power hum, gunshot, radio static, transformer buzz, and final resonance should anchor the morning.

| Cue | Source timing / status |

| Collision | 8:04:45, only if collision actually occurs |
| Welder | 8:09:05, only if Ellis activates it |
| Gunshot | 8:11, only if shooting actually occurs |
| Radio static / power anomaly | 8:13 default |
| Resonance collapse | 8:15 default |
| Other recurring ambient cues | Exact times not yet authored |

Eventually a player may recognize the collision from elsewhere in town. This requires an intentional audibility map; not every cue should be globally audible. A missing cue can communicate a changed chain.

**PROPOSED:** gameplay cues are emitted by committed simulation events, never an unconditional music timeline. Caption or visual equivalents should preserve useful timing information for players who cannot hear them. A caption must not reveal a remote event beyond its intended perceptual range.

Keep familiar catastrophe sounds in the safe ending long enough to sustain uncertainty; let ordinary ambience and music mark survival. The 8:16 bell's cause is still proposed in [endings](08_ENDINGS.md).
