# Art direction

**Direction only. Do not create finished art during this phase.**

2D pixel art, top-down / three-quarter view, readable silhouettes over detail. Target internal resolution: **640 × 360**.

Greywick: autumn leaves, cold fog, old brick, telephone poles, fogged café windows, fluorescent lights. Peaceful, ordinary, nostalgic, slightly wrong.

| Motif | Palette |
| --- | --- |
| Morning | Warm amber |
| Meridian | Cold cyan / white |
| Knowledge / notebook | Paper cream |
| Danger | Deep crimson |

| Landmark | Recognition cue |
| --- | --- |
| Church | Tall red steeple |
| Café | Green awning |
| Police | Blue lamps |
| Florist | Purple sign |
| Observatory | Large white dome |
| Substation | Industrial lattice towers |

Avery: dark jacket + red scarf. NPC appearance directions are owned by [the character bible](04_CHARACTER_BIBLE.md).

For paper validation, use labeled tokens and blocks. Later prototypes should test whether routes, characters, interactables, and moving evidence remain legible at the target resolution. Color should reinforce labels and silhouettes rather than being the only identifier. No asset purchases, 25 finished portraits, or whole-town art pass yet.
