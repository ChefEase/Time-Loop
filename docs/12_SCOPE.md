# Scope lock

**CANON v0.1.** Solo project. Full production blocked.

## Included at intended full scope

One town; one fifteen-minute window; 25 major characters including Avery; 6–10 meaningful interiors; about five major causal chains plus several minor chains; four permanent alternate-ending concepts, Justice discovery/reset, and one true ending; Windows first; single-player; offline; 2D.

The map names more buildings than the interior budget. Named locations need not all have explorable interiors. Assign the 6–10 interior slots before a vertical slice; use exterior interactions where sufficient.

## Excluded

Open world, multiplayer, character creation, combat system, crafting, random loot, procedural town, hundreds of simulated NPCs, drivable cars, online servers, mobile/PlayStation/Xbox launch, romance system, day/night cycle, multiple cities, multiple fifteen-minute scenarios, fully voiced dialogue.

Weapon removal in a puzzle is a contextual intervention, not permission to add a combat system. An Echo ending is not permission for multiple playable time periods.

## Pre-production prohibitions

Do not draw 25 finished characters, compose the soundtrack, write 50,000 dialogue words, build the whole town, create advanced NPC AI, buy packs, make trailers, create a Steam page, implement saves, build every ending, or ask an agent to create the entire game.

Current deliverables: documents, contradictions audit, guarded causal model, desk traces, paper prototype, playtest criteria, and gate evidence.

## Development order after the relevant gate

1. Empty Godot project.
2. Movement and interaction.
3. Clock, event system, physical world state.
4. One scheduled NPC, then five.
5. Conditional schedules, loop reset, persistent knowledge.
6. Three-minute causal prototype.
7. Playtest and continue/redesign decision.
8. Vertical slice.
9. Full production only after prototype and slice evidence.

The prototype has five NPC roles including the officer and courier; the machine is an object. This satisfies the intended small-scope progression.

## Change filter

Does the change improve experimenting with causality? What existing scope does it replace? What is its smallest paper test? If those answers are weak, defer it. A detailed idea is not automatically a scheduled feature.
