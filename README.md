# 8:15

**PRE-PRODUCTION — full production is not approved.**

A deterministic, 2D time-loop detective game set in Greywick, 1998. Every morning at 8:15 the town collapses; at 8:00 Avery Vale wakes again. Knowledge is progression.

Solo development. Windows / Steam first. Planned engine: Godot .NET with C#.

Start with [the project guide](docs/00_START_HERE.md). Read [the design audit](docs/14_DESIGN_AUDIT.md), then [the paper simulations](docs/15_PAPER_SIMULATION.md). The [three-minute prototype specification](docs/16_PROTOTYPE_SPEC.md) is a design document, not permission to implement it.

This directory is the project home; a second `815/` directory is unnecessary. This pre-production delivery contains design documents only. No engine project, production assets, save system, or gameplay implementation was created as part of this work. A separate `time-loop/` directory appeared in the workspace during documentation work; it is outside this delivery and is left untouched and untracked by this commit.
